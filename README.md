# CI/CD — Caso de uso

Repositorio de una página web estática con información general sobre **CI/CD (Integración Continua y Entrega/Despliegue Continuo)**.

## 📁 Estructura

```text
cicd-caso-uso/
├── index.html
├── styles.css
└── README.md
```

## 📝 Descripción

La página presenta de forma resumida:

- Qué es CI/CD.
- Qué significa Integración Continua (CI).
- Qué significa Entrega Continua (Continuous Delivery).
- Qué significa Despliegue Continuo (Continuous Deployment).
- Cómo funciona un pipeline CI/CD.
- Herramientas utilizadas en CI/CD.
- Ventajas y desafíos.
- Un caso de uso práctico de una aplicación web.
- Una conclusión general.

## 🛠️ Tecnologías

El proyecto utiliza únicamente:

- HTML5
- CSS3

No utiliza JavaScript ni librerías externas.

## ▶️ Ejecución local

No se necesita instalar ninguna dependencia.

1. Descarga o clona el repositorio.
2. Abre el archivo `index.html` en cualquier navegador web.

También puedes utilizar una extensión como **Live Server** en Visual Studio Code para visualizar los cambios mientras editas.

## 🚀 Publicación

El proyecto puede publicarse como un sitio estático en servicios como GitHub Pages, GitLab Pages o cualquier servidor web que permita servir archivos HTML y CSS.

## 🎯 Objetivo académico

El objetivo es presentar un caso de uso investigado relacionado con CI/CD mediante una página web sencilla, clara y sin elementos interactivos.
